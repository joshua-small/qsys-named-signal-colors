Named Signal Colors 0.1.1

Palette preferences now use the same color picker as Q-SYS Designer 10.5's signal-trace preferences, with a swatch, popup picker and exact color entry. Scroll to reach all 24 roles.

Existing opaque RGB palettes are preserved. OK saves the changes and refreshes an existing preview; Cancel discards the edits. Signal colors still change only when you explicitly apply a preview.

Requires the approved Designer 10.5 build, Q-SYS Mods Core 0.1.x and Q-SYS Mod Manager 0.8 or later. Close Designer before installing the update, then reopen it.
